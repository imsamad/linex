# Introduction

Operating System is program used to manage the hardware resources and all the programs running on system.

## Lets demistify this definition

First **_Understand Computer System Architechure_**

#### Computer System Architechure

Computer System consist of hardware and software. Minimum required hardware devices are CPU, Memory, Storage device(s), Input And Output device(s).

##### Prequisite to know about these devices.

1. **_Memory_** - Used to store the programs/software.
2. **_CPU_** - Read/Understand those programs from memory and execute the task.
3. **_Input Devices_** - Used to take input from outside.
4. **_Output Devices_** - Used to produce or show the result to user in audio/video/textual format.
